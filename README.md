## About The Project

[![Product Screenshot][product-screenshot]](https://allanroz.github.io/Muscle-Finder-Map/)

**MuscleFinder** is an interactive web application that helps users learn which exercises target specific muscle groups across the body. Instead of manually searching through workout lists, users can interact directly with a 2D anatomical body map (front and back views) to instantly view exercises, video tutorials, secondary muscle activations, and smart workout suggestions.

### Key Features

* **Interactive 2D Muscle Graphic:** Clickable anterior (front) and posterior (back) body views with glowing neon highlights for active target muscles.
* **Dynamic Exercise Discovery:** Click any muscle group to reveal a list of effective target exercises.
* **Video Demos & Instructions:** Embedded YouTube video demonstrations and execution cues for every workout.
* **Secondary Muscle Activation:** Displays auxiliary muscles hit during compound exercises (e.g., highlighting Triceps and Front Delts when viewing Bench Press).
* **Smart Complementary Targets:** Recommends opposing muscle groups to balance your workouts (e.g., suggesting Lats after targeting Chest).

## Getting Started

Follow these steps to set up and run a local copy of the project on your machine.

### Prerequisites

* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation and running a React app locally
1. Clone the repo
   ```sh
   git clone https://github.com/AllanRoz/Muscle-Finder-Map.git
   ```
2. Change into the project directory
   ```sh
   cd Muscle-Finder-Map
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Running the React app locally
   ```sh
   npm run dev
   ```
